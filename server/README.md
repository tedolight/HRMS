# Backend

Backend entry point: `server.js`.

## Structure

- `src/config` - database, environment, and system configuration
- `src/controllers` - request handlers and responses
- `src/middlewares` - request processing and validation
- `src/models` - database models and validation
- `src/routes` - API endpoint definitions
- `src/services` - business logic and persistence
- `src/utils` - reusable helpers
- `test/unit` - unit tests
- `test/integration` - integration tests

Run the server with `npm start`.
